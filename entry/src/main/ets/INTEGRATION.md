# 张睿祥负责模块的联调约定

此入口模块提供知识检索、来源引用、对话消息展示与取消、页面布局，以及表单、学习、魔方和语音的接口边界。生产索引、模型推理、设备能力和本地加密存储需各自负责人注入；默认适配器会明确返回“服务尚未接入”，不会伪造请求成功。统一注册位置为 `services/IntegrationService.ets`。

## M7 检索数据侧

由数据侧注入 `KnowledgeRepository` 和可选的 `QueryEmbedder`。`snapshot()` 一次返回同一索引版本：

- `revision` 是每次索引更新的稳定版本标识。
- 每段 `KnowledgeChunk` 有稳定唯一的 `id`、文档级 `sourceId`、原始资料标题、章节或页码 `location`、课程 `course` 和用于引用的 `content`。
- `vector` 与 `vectorModel` 成对提供。`QueryEmbedder.modelId` 必须与文档向量所用模型一致；维数和模型不匹配的片段只参与关键词搜索。
- 每一处内容与位置应能回溯到原始文档；文档解析、切块、向量生成、索引存储和联网兜底由 M7 数据侧承担。

`RagService.search(query, options)` 会按选择的课程过滤片段，执行中文字符二元组与英文词的 BM25 关键词检索；有匹配模型向量时，将关键词得分与余弦相似度合并。默认最多返回 4 个片段、每份资料最多 2 段，截取的资料文本预算为 2400 个字符。低于相关度阈值的片段不入选。每条结果包含稳定编号、来源、章节、原文片段和分数；检索不到时返回空引用和明确提示，不自动把猜测内容当成资料。

请将一份索引版本的全部片段一次传给 repository，避免生成过程读到正在更新的索引。空文档、空片段和重复 ID 会被检索过滤。演示索引中的课程资料仅供离线演示，并不代表学校官方资料。

## Agent 消息流

通过 `IntegrationService.agent` 注册 `AgentGateway`。`generate(request, sink)` 收到用户问题、最近 12 条历史（每条最多 4000 字符）、当前功能 ID、检索结果和引用策略。适配器对 `request.retrieval.context` 必须按**不可信资料**处理；只给有资料支持的句子加 `[编号]`，缺少证据时明确说明。模型供应商、API 凭据和重试由 Agent/模型适配层管理，不能将 API Key 写入 ArkTS 源码或打包资源。

每次 `sink.onDelta` 交付一段增量文本。用户取消、切换页面或等待超过 30 秒后，`sink.isCancelled()` 会返回 `true`；适配器应检查取消状态并尽快停止网络读取与计费。UI 只保存本次进程中的最近 100 条会话消息。要提供重新打开后的对话记录，M8 负责人需要把 `SessionService` 的进程内存储换为获准的本地加密存储。

## 其他页面接口

在 `IntegrationService` 注册各自的 `ModuleAdapter`：`forms` 执行模板、草稿、导出和辅助填充；`study` 执行课表、提醒、计划、打卡和复习手册；`hardware` 执行连接、姿态查询和专注控制。按 `ModuleResult.ok` 判断操作成功，只将成功响应中的 items 展示为实际结果。

在 `IntegrationService.voice` 注册 `VoiceAdapter`。`start()` 开始采集，`stop()` 结束并返回待用户核对的识别文本，`cancel()` 立即释放输入设备。`speak(text)` 播报回答，`stopSpeaking()` 中断播报。UI 不会在用户确认前自动发送识别内容。语音权限申请与平台 ASR/TTS 由语音负责人完成。

检索入口复用聊天标题栏的“＋上下文”、输入框旁的“＋”和首页快捷项。资料选择器嵌在当前会话上方，用户可预览原文并逐条加入或移除引用；发送消息时把这些资料与当轮检索合并，再把统一编号后的引用交给 Agent 和消息列表。常用工作区、聊天气泡、侧栏和任务面板保持原有布局。主要操作按键至少 44 vp，引用文字可复制。
